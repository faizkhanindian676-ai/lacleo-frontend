// Run controls

Three things you can do to any run

Not just cosmetic — these actually change what's happening in the background.

● WATCH

Live progress

Cards fill in as each lead clears verification, with a stage label so you know exactly what's happening right now.

■ STOP

Stop a run

Halts the run immediately — no further research or verification calls go out. Whatever was already verified is still delivered as a report.

✕ DELETE

Delete a run

Removes it from your dashboard for good. Nothing left behind to explain to a teammate later.
